AIVAROCART — START HERE

1. Open index.html in a browser to view the customer storefront.
2. Open index.html?admin=1 to open the separate Admin screen.
3. Demo PIN: 246810 (prototype only; not secure for a real store).
4. In Admin, open Store content to edit banner slides and upload up to 3 banner images. The home banner auto-rotates every 3 seconds.
5. Product details, cart, demo checkout, review flow and admin tools are interactive in this browser prototype.

IMPORTANT: Data lives only in this browser/device. Banner uploads, product photos, orders and admin settings do not sync to other phones. The AI Manager is rule-based demo logic, not a connected AI service. No real payment or delivery order is created. Do not use this prototype to accept real customer payments or orders.

For a real store, connect Supabase Auth/Database/Storage, enforce Admin permissions server-side, and implement trusted checkout, stock validation and payment verification before launch. See aivarocart_supabase_phone_guide.txt.
